# Citability checklist

Use before Accept on any hub publish or refresh.

## URL & chrome
- [ ] Canonical URL stable (no date-only URLs that will rot yearly without redirect plan)
- [ ] Year in H1/title; **Last updated** visible above the fold
- [ ] TOC / jump links to national, state, local sections
- [ ] No intrusive popups/paywall on the hub

## Each stat block
- [ ] Answer-first claim line (copy-paste friendly)
- [ ] Exact figure matches source
- [ ] As-of date present
- [ ] Source org named
- [ ] Source URL live (or archived with note)
- [ ] Layer tag: national | state | local
- [ ] Stable `#stat-…` anchor id
- [ ] Status = verified (not quarantine)

## Page trust
- [ ] Methodology blurb
- [ ] Author/org clear (SAA / Schwartz & Associates)
- [ ] Fair Housing safe
- [ ] Internal links: local stats → money pages; money pages → hub
- [ ] Schema honest (Article/WebPage; FAQ only if real)

## Dual-layer intent
- [ ] ≥1 national magnet section a national editor could cite without local context
- [ ] ≥1 local cluster section that supports money URLs
- [ ] Angle Map scored (not local-only by default)

## Continuous
- [ ] Ledger updated in `bus/citation-hub/INDEX.md`
- [ ] Next refresh date set
- [ ] Monitor routine armed after first publish
