# Topical Authority Glossary

## Owns
Harvest, score, architecture, and produce **one-entity-per-URL definition pages** plus an A–Z hub so search and LLMs treat the site as the definition layer for the niche. Includes **national category terms** and **local/program entities** — do not limit the inventory to city pages only. Pair with `citation-hub-builder` for numbers; this skill owns definitions.

## Stopline
- No thin doorway spam. Every term page must earn its URL (clear search/AI utility).
- No invented definitions for legal/finance/YMYL — cite primary sources; Fair Housing always.
- Never publish/deploy without Accept.
- Do not duplicate the citation hub; link to hub stats when a definition needs a number.
- Prefer quality batches over dumping hundreds of empty stubs.

## Doctrine
Engines grant topical ownership when you cover the **concept graph**, not one keyword: each important term has a clean URL, definition in the first ~50 words, related-term links, byline/date/sources. Glossaries also attract links over time because they are easy to cite for “what is X?”.

## Inventory scoring
Harvest from: site crawl, GSC queries, competitor glossaries, sales/FAQ language, program names (e.g. CHFA), national RE vocabulary.
Score: `intent × demand × gap × link_to_money_page × AI_definition_likelihood`.
Tag each term: `national | state | local | program`.

## Page anatomy
- URL: `/glossary/{term-slug}/` (flat) + hub `/glossary/`
- H1 = query form (“What is earnest money?”)
- Definition in first 50 words
- Progressive depth: example, local/NoCO note when relevant, CTA to money page
- Related terms in body
- Sources + date + author/org
- DefinedTerm / FAQ schema only when honest

## Steps
1. Crawl what exists; build scored inventory → `bus/glossary/inventory.md`.
2. Architecture wireframe: hub + batch order (highest score first).
3. Accept on batch plan when creating many URLs.
4. Produce pages to template; wire internal links both ways (glossary ↔ money ↔ citation hub).
5. Expand on cadence (weekly N terms); refresh stale definitions quarterly.
6. Measure: GSC on `/glossary/*`, AI “what is” spot-checks, inbound links to term URLs.

## Output contract
- Inventory summary + next batch list
- Template confirmation
- URLs produced or brief for Code
- Internal link plan
- Proof paths
- Engine named

## SAA Homes defaults (not a ceiling)
National: earnest money, contingency, DOM, PITI, pre-approval, etc.
State/program: CHFA, Colorado Champions, Schools to Home, …
Local entities: city/metro terms that support Tier-S realtor queries
Cross-link every local definition to the matching city or program money page; cite the stats hub for figures.
