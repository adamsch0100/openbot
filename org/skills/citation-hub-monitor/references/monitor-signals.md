# Monitor signals

## Primary KPIs
1. New referring domains → hub (weekly)
2. Lost referring domains (weekly alert)
3. Citing-page quality sample (relevance + context quotes the number)
4. Freshness: % stats verified ≤90 days; broken source count
5. GSC clicks/impressions on hub URL
6. GEO spot-check hit rate (monthly)

## Secondary
- Deep-link cites to `#stat-` anchors (if visible in tools)
- Section-level cite inference (national vs local)
- Competitor outdated roundups (outreach opportunity notes only)

## Alert thresholds (defaults; tune per CEO)
- Any broken source on a previously verified magnet stat → builder within 7 days
- Lost link from DR50+ domain → log + optional outreach draft
- 0 new referring domains for 45 days after publish → builder expand national angles
- Verified_pct < 70% → quarterly full re-verify

## Evidence labels
- VERIFIED: tool/API or live fetch proof
- INFERRED: search sample / partial data
- UNKNOWN: credential or access missing — say so plainly
